# PULSE — Night Circuit

Cinematic arcade street racing in the browser. Night rain, neon downtown, nitro, drift, and a full race loop against AI.

## Run

```bash
npm install
npm run dev
```

Open the local URL (default `http://localhost:5173`).

## Controls

| Key | Action |
| --- | --- |
| W / ↑ | Accelerate |
| S / ↓ | Brake / Reverse |
| A / ← | Steer left |
| D / → | Steer right |
| Space | Handbrake / drift |
| Shift | Nitro |
| C | Camera (chase / bumper / hood) |
| Esc | Pause |
| R | Restart |

Gamepad: left stick steer, RT/A throttle, LT/B brake, X/LB handbrake, Y/RB nitro.

## Stack

Three.js · WebGL2 · Web Audio · Vite
